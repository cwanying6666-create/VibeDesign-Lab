# 联系区创意挂卡

用户圈出的联系区人物改为 React Bits Lanyard，沿用现有白底、电光蓝 `#173ef5`、浅紫 `#d3c5fa` 和粉色 `#f9c3e5`。正面复用网站的 scientist IP，背面保留明确的联系方式占位，挂绳印有「浪味设计所 / VIBE DESIGN」。

## 修改内容

- `src/content.ts` 中的 `contactPass` 管理正面、背面、挂绳资源和交互提示。
- `public/assets/lanyard/` 保存三张可替换 SVG 贴图，正面嵌入现有 IP 图片以供 WebGL 读取。
- `src/components/ContactLanyard.tsx` 负责进入视口前的延迟加载和静态回退。
- `src/components/react-bits/Lanyard.tsx` 来自官方 TypeScript 版本，保留目录中的许可；本地增加键盘翻面、方向键摆动、加载完成回调和 WebGL 上下文丢失回退。
- 组件松手后自然摆动并停止，不设置持续风力。Canvas 外部保留页面纵向滚动。

来源：https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Components/Lanyard

## 本轮调整

挂绳从联系模块顶边开始，位于标题文字下层；保留卡片的原有大小和落点。去掉卡面 AI 徽标与卡片下方说明，放大品牌名、姓名及辅助文字。构建通过，并在浏览器确认挂绳起点、文字层级和卡面显示。

## 整模块拖拽热区

Canvas 扩展为联系模块全宽、全高，保持原有卡片大小和悬挂位置。卡片外的空白处也可拖动，按下时记录偏移，避免卡片突然跳到鼠标位置；仅直接点击卡片才触发翻面。标题仍位于挂绳上层，联系按钮和社交入口保留独立区域。浏览器实测从左侧空白处拖动可带动挂卡，Canvas 高度与联系模块一致，构建通过。

## 卡面图片调整

移除正面底部姓名、身份英文和页脚文字，将人物从 590×710 放大为 710×854，并将图片背景延伸到卡面底边；保留顶部品牌信息。
