# 课程打字机

本地入口：`http://127.0.0.1:5187/#courses`。

使用现有奶油白与浅紫色打字机，保留当前 Pen 页面布局与配色。交互参考 https://iamadrianpunk.com/#consult ，独立实现原生 Web Animations、React 状态和 CSS 送纸，不引入视频或新增动画依赖。

## 修改内容

- `src/content.ts` 的 `coursePrintout`：用户确认的完整课程文案，纸张与文字版共用。
- `src/components/CourseTypewriter.tsx`：进入视野触发、逐字显字、逐行送纸、键盘按键采样动画、重播、暂停/继续、全文显示和可选音效。
- `src/components/CourseTypewriter.css`：独立课程样式，使用原站颜色变量，按屏幕高度缩放场景。
- `PortfolioPage.tsx`：课程图替换为交互组件；查看课程按钮展开并定位文字版。

文本保持 HTML，可编辑、复制；无需重做图像。键盘覆盖层通过同一张图片的坐标采样，按键下压用 Web Animations；纸张在机身后由裁切窗口控制，不需要额外拆分素材。机身外围柔光通过 CSS clip-path 遮罩处理。

离开视野和切到后台暂停，返回时继续；手动暂停保持暂停。系统设置减少动态效果时直接展示全文。音效默认关闭，用户点击后才初始化 Web Audio，使用短噪声合成敲击声。
